# 文档索引

这个目录是项目交接和长期维护的入口。接手者优先从这里读，不要先翻聊天记录。

## 推荐阅读顺序

1. [AI 交接文档](./AI_HANDOFF.md)
   - 当前进度、架构、关键决策、测试方式、下一步优先级。
   - 给新的 AI 或开发者快速接手用。

2. [规则系统语义矩阵](./rule-system-semantics.md)
   - 逐类说明从新版沉浸式翻译规则库吸收了哪些字段。
   - 说明字段在本项目里是已执行、部分执行、跳过，还是仅保留为元数据。

3. [导入规则运行时](./imported-rule-runtime.md)
   - 说明 830 条导入规则如何按 URL 懒加载、能力过滤、分类和合并。

4. [验证清单](../VERIFY.md)
   - 当前自动化检查、真实站点回归、手动浏览器验证步骤。

5. [实施计划归档](./superpowers/plans/)
   - 历史实现计划。用于理解某些模块为什么按现在的方式设计。

## 维护约定

- 改动网页翻译内核时，同步更新 [AI 交接文档](./AI_HANDOFF.md) 的“当前能力”和“下一步”。
- 改动规则字段语义时，同步更新 [规则系统语义矩阵](./rule-system-semantics.md)。
- 新增或删除真实站点回归目标时，同步更新 [验证清单](../VERIFY.md)。
- 不要把聊天里的临时判断当成事实写进文档；用代码路径、测试、审计脚本或真实站点回归支撑结论。
